# 感情グラフ日記

毎日の感情変化を、感情語・時刻・場面・考え・IF・行動と一緒に記録できるAndroidアプリです。

## ダウンロード

[最新版APKをダウンロード](https://github.com/Ryoyavx/emotion-graph-diary-downloads/releases/latest/download/EmotionGraphDiary-2.2.0.apk)

現在のバージョン：2.2.0
対応OS：Android 8.0以降

## 2.2.0の主な変更

- 「自己理解・特性メモ」とAI相談を「自己理解・AI整理」画面へ統合
- 感情値、感情語、日別メモ、特性メモを日付単位でPCへ送信する機能を追加
- 未送信・更新ありの日付を選んでまとめて送信できる機能を追加
- 本人のWindows PC、非公開Google Driveフォルダ、ChatGPT Scheduled Tasksを使う総合分析に対応
- 07:00の日次助言と、最短1時間間隔のGmail合図監視に対応
- JSONバックアップをv5へ更新し、JSON v1～v4の読込互換を維持

## インストール方法

1. 上のリンクからAPKをダウンロードします。
2. Androidの確認画面で、使用したブラウザに「不明なアプリのインストール」を一時的に許可します。
3. ダウンロードしたAPKを開いてインストールします。
4. インストール後は、その許可をオフへ戻せます。

## 更新について

同じ署名の旧版が入っている場合は、記録を保持したまま上書き更新できます。

1. 念のため、旧版アプリの「バックアップ・復元」からJSONバックアップを保存します。
2. **旧版アプリをアンインストールしないでください。**
3. 2.2.0 APKをダウンロードして開き、Androidの更新確認画面からインストールします。

通常の上書き更新では、記入済みグラフや設定は削除・全置換されません。時刻入力済みの
既存ポイントはその時刻へ再配置され、時刻未設定ポイントもデータを保持したまま表示されます。

旧版を先にアンインストールした場合、またはAndroid設定からアプリのストレージを消去した場合は、
端末内の記録が削除されます。その場合は保存済みJSONバックアップから復元してください。

## プライバシー

- 記録は端末内に保存されます。
- アカウント登録、広告、不要な通信権限はありません。
- AI整理はADB接続した自分のWindows PC、本人アカウントの非公開Google Driveフォルダ、
  ChatGPT側のタスク設定が必要です。APK単体では自動回答されません。
- Androidアプリは通信権限を持たず、本人が送信操作をした記入済み感情値、感情語、
  日別メモ、特性メモだけをPC経由で送ります。
- Gmailの合図メールには記録本文や健康情報を含めません。
- この公開リポジトリにはAPKと配布説明だけを置き、アプリのソースコードや利用者データは含めません。
