# 感情グラフ日記

毎日の感情変化を、感情語・時刻・場面・考え・IF・行動と一緒に記録できるAndroidアプリです。

## ダウンロード

[最新版APKをダウンロード](https://github.com/Ryoyavx/emotion-graph-diary-downloads/releases/latest/download/EmotionGraphDiary-2.1.0.apk)

現在のバージョン：2.1.0
対応OS：Android 8.0以降

## 2.1.0の主な変更

- 「未記入」と記入済みの感情値0を区別
- 設定したポイント時刻の通知と、15分・30分・60分の未記入スヌーズを追加
- 欠損を明示して近接する記録をつなぐ1週間・1か月・1年の期間グラフを追加
- お気に入り、よく使う、最近使用、五十音、使用回数、最終使用日時を全て系統別に表示
- 日別メモとは別の「自己理解・特性メモ」を追加
- 本人が送信した相談だけをADB経由で自分のWindows PCへ渡すAI相談画面を追加
- JSONバックアップをv4へ更新し、JSON v1～v3の読込互換を維持

## インストール方法

1. 上のリンクからAPKをダウンロードします。
2. Androidの確認画面で、使用したブラウザに「不明なアプリのインストール」を一時的に許可します。
3. ダウンロードしたAPKを開いてインストールします。
4. インストール後は、その許可をオフへ戻せます。

## 更新について

同じ署名の旧版が入っている場合は、記録を保持したまま上書き更新できます。

1. 念のため、旧版アプリの「バックアップ・復元」からJSONバックアップを保存します。
2. **旧版アプリをアンインストールしないでください。**
3. 2.1.0 APKをダウンロードして開き、Androidの更新確認画面からインストールします。

通常の上書き更新では、記入済みグラフや設定は削除・全置換されません。時刻入力済みの
既存ポイントはその時刻へ再配置され、時刻未設定ポイントもデータを保持したまま表示されます。

旧版を先にアンインストールした場合、またはAndroid設定からアプリのストレージを消去した場合は、
端末内の記録が削除されます。その場合は保存済みJSONバックアップから復元してください。

## プライバシー

- 記録は端末内に保存されます。
- アカウント登録、広告、不要な通信権限はありません。
- AI相談はADB接続した自分のWindows PCと別途コンパニオン設定が必要です。APK単体では
  自動回答されず、グラフ、日別メモ、感情語、特性メモを自動送信しません。
- この公開リポジトリにはAPKと配布説明だけを置き、アプリのソースコードや利用者データは含めません。
