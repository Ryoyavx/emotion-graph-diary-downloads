# 感情グラフ日記

毎日の感情変化を、感情語・時刻・場面・考え・IF・行動と一緒に記録できるAndroidアプリです。

## ダウンロード

[最新版APKをダウンロード](https://github.com/Ryoyavx/emotion-graph-diary-downloads/releases/latest/download/EmotionGraphDiary-1.1.0.apk)

現在のバージョン：1.1.0  
対応OS：Android 8.0以降

## インストール方法

1. 上のリンクからAPKをダウンロードします。
2. Androidの確認画面で、使用したブラウザに「不明なアプリのインストール」を一時的に許可します。
3. ダウンロードしたAPKを開いてインストールします。
4. インストール後は、その許可をオフへ戻せます。

## 更新について

同じ署名の旧版が入っている場合は、記録を保持したまま上書き更新できます。念のため、更新前にアプリの「バックアップ・復元」からJSONバックアップを保存してください。

## プライバシー

- 記録は端末内に保存されます。
- アカウント登録、広告、不要な通信権限はありません。
- この公開リポジトリにはAPKと配布説明だけを置き、アプリのソースコードや利用者データは含めません。
