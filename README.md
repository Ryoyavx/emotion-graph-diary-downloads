# 感情グラフ日記

毎日の感情変化を、感情語・時刻・場面・考え・IF・行動と一緒に記録できるAndroidアプリです。

## ダウンロード

[最新版APKをダウンロード](https://github.com/Ryoyavx/emotion-graph-diary-downloads/releases/latest/download/EmotionGraphDiary-2.0.0.apk)

現在のバージョン：2.0.0
対応OS：Android 8.0以降

## 2.0.0の主な変更

- 感情グラフを00:00～23:59の1分精度・横スクロール時間軸へ変更
- 毎正時、30分、15分・45分の時間目盛りを追加
- 時刻を確定してからポイントを追加し、同一時刻の新規登録を防止
- 初期ポイント時刻を編集する専用の「ポイント数設定」画面を追加
- PNG・PDF・CSVを24時間軸・時刻順へ更新
- JSONバックアップをv3へ更新し、JSON v1/v2の読込互換を維持

## インストール方法

1. 上のリンクからAPKをダウンロードします。
2. Androidの確認画面で、使用したブラウザに「不明なアプリのインストール」を一時的に許可します。
3. ダウンロードしたAPKを開いてインストールします。
4. インストール後は、その許可をオフへ戻せます。

## 更新について

同じ署名の旧版が入っている場合は、記録を保持したまま上書き更新できます。

1. 念のため、旧版アプリの「バックアップ・復元」からJSONバックアップを保存します。
2. **旧版アプリをアンインストールしないでください。**
3. 2.0.0 APKをダウンロードして開き、Androidの更新確認画面からインストールします。

通常の上書き更新では、記入済みグラフや設定は削除・全置換されません。時刻入力済みの
既存ポイントはその時刻へ再配置され、時刻未設定ポイントもデータを保持したまま表示されます。

旧版を先にアンインストールした場合、またはAndroid設定からアプリのストレージを消去した場合は、
端末内の記録が削除されます。その場合は保存済みJSONバックアップから復元してください。

## プライバシー

- 記録は端末内に保存されます。
- アカウント登録、広告、不要な通信権限はありません。
- この公開リポジトリにはAPKと配布説明だけを置き、アプリのソースコードや利用者データは含めません。
